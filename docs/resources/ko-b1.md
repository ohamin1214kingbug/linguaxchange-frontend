TOPIK 3 is where Korean starts to sound like real conversation. You can pass on what someone said, guess politely, share something you noticed, and link your ideas with endings that carry nuance, not just "and" and "but".

## What you'll be able to do | short: I can… | kicker: Your goal
- [ ] Tell someone what another person said or asked
- [ ] Guess and soften your statements: "it seems…"
- [ ] Share something you saw or experienced yourself
- [ ] Give background, contrast and reasons in one sentence
- [ ] Understand everyday news and announcements on familiar topics
- [ ] Handle problems: complaints, changes and cancellations

## It seems… | short: It seems | kicker: Grammar · 1 of 5
Koreans soften statements constantly with **-(으)ㄴ/는/(으)ㄹ 것 같아요** ("it seems", "I think"). The modifier shows the time.

| Time | Verb | Example |
|---|---|---|
| now | -는 것 같아요 | 비가 오는 것 같아요. // It seems to be raining. |
| past | -(으)ㄴ 것 같아요 | 민수가 벌써 간 것 같아요. // I think Minsu has already left. |
| future, guess | -(으)ㄹ 것 같아요 | 내일 추울 것 같아요. // I think it'll be cold tomorrow. |
| adjective now | -(으)ㄴ 것 같아요 | 이 가방이 좀 비싼 것 같아요. // This bag seems a bit expensive. |

:::tip
This is also the polite way to give an opinion: *이게 더 좋은 것 같아요* sounds softer and more natural than *이게 더 좋아요*.
:::

:::mistake
- 비가 와는 것 같아요. => 비가 오는 것 같아요.
-는 attaches straight to the stem: 오 + 는.
:::

:::practice
1. 지금 자___ 것 같아요. (now) = 는
2. 이 영화가 재미있을 것 ___. = 같아요
3. 그 사람이 벌써 ___ 것 같아요. (가다, past) = 간
:::

## Connectors with nuance | short: Connectors | kicker: Grammar · 2 of 5
| Ending | Meaning | Example |
|---|---|---|
| -는데 / -(으)ㄴ데 | background, "so / but…" | 배가 고픈데 밥 먹을래요? // I'm hungry, shall we eat? |
| -(으)면서 | while (same person) | 음악을 들으면서 공부해요. // I study while listening to music. |
| -기 때문에 | because (firm reason) | 시험이 있기 때문에 못 가요. // I can't go because I have an exam. |
| -(으)ㄹ 때 | when | 한국에 있을 때 김치를 많이 먹었어요. // I ate a lot of kimchi when I was in Korea. |

:::tip
-는데 is the most useful ending at this level: it sets the scene before a question, request or contrast. *제가 지금 바쁜데 나중에 전화할게요* = I'm busy now, so I'll call you later.
:::

:::mistake
- 친구가 노래하면서 제가 춤을 췄어요. => 친구가 노래하는 동안 제가 춤을 췄어요.
-(으)면서 needs the same person doing both actions. Use -는 동안 for two people.
:::

:::practice
1. 밥을 먹___ 텔레비전을 봐요. (while) = 으면서
2. 비가 오___ 우산이 없어요. (background) = 는데
3. 어렸___ 때 부산에 살았어요. = 을
:::

## Reporting what people said | short: Reported speech | kicker: Grammar · 3 of 5
Indirect speech changes the ending depending on whether the original was a statement, question, suggestion or command.

| Original | Ending | Example |
|---|---|---|
| statement | -다고 해요 / -ㄴ다고 해요 | 민지가 바쁘다고 했어요. // Minji said she was busy. |
| question | -냐고 해요 | 어디 가냐고 물어봤어요. // He asked where I was going. |
| suggestion | -자고 해요 | 같이 가자고 했어요. // She suggested going together. |
| command | -(으)라고 해요 | 일찍 오라고 했어요. // He told me to come early. |

:::tip
In speech the ending shortens: *바쁘대요* (they say they're busy), *가재요* (they suggest going). You'll hear these constantly.
:::

:::mistake
- 선생님이 숙제를 하세요라고 했어요. => 선생님이 숙제를 하라고 했어요.
Reported commands use the plain -(으)라고.
:::

:::practice
1. 친구가 내일 온___ 했어요. (statement) = 다고
2. 엄마가 밥 먹으___ 했어요. (command) = 라고
3. 동생이 영화 보___ 했어요. (suggestion) = 자고
:::

## What I saw: -더라고요 | short: -더라고요 | kicker: Grammar · 4 of 5
**-더라고요** shares something you saw, heard or experienced yourself, often with a hint of surprise.

:::examples
- 그 식당 음식이 정말 맛있**더라고요**. // The food at that restaurant was really good, you know.
- 어제 가 보니까 문이 닫혀 있**더라고요**. // When I went yesterday, it turned out to be closed.
- 한국 사람들이 정말 빨리 걷**더라고요**. // I noticed Koreans walk really fast.
:::

:::mistake
- 제가 어제 피곤하더라고요. => 저는 어제 피곤했어요.
You don't observe your own feelings from the outside, so -더라고요 is rarely used for them.
:::

## Passive verbs | short: Passive | kicker: Grammar · 5 of 5
Many common verbs have a passive form made with **-이-, -히-, -리-, -기-**. Learn them as new words.

| Active | Passive | Example |
|---|---|---|
| 보다 (see) | 보이다 (be seen) | 산이 보여요. // You can see the mountain. |
| 열다 (open) | 열리다 (be opened) | 문이 열렸어요. // The door opened. |
| 닫다 (close) | 닫히다 (be closed) | 가게가 닫혔어요. // The shop is closed. |
| 듣다 (hear) | 들리다 (be heard) | 소리가 들려요. // I can hear a sound. |

:::practice
1. 창문이 ___. (열다, passive, past) = 열렸어요
2. 여기서 바다가 ___. (보다, passive) = 보여요
:::

## Passing on news | short: Conversation | kicker: Put it together
:::dialogue
- 지은: 민수 씨가 다음 주에 이사한대요. // Minsu says he's moving next week.
- 준호: 정말요? 어디로 간다고 했어요? // Really? Where did he say he's going?
- 지은: 부산으로 간다고 했어요. 회사가 거기 있대요. // He said Busan. Apparently his company is there.
- 준호: 그렇구나. 부산 좋더라고요. 작년에 가 봤는데 바다가 정말 예뻤어요. // I see. Busan is nice, you know. I went last year and the sea was really beautiful.
- 지은: 우리 같이 송별회 하자고 할까요? // Shall we suggest a farewell party?
- 준호: 좋아요! 다들 바쁠 것 같은데 주말에 하면 될 것 같아요. // Sure! Everyone seems busy, but the weekend should work.
:::

## Watch out for | short: Watch out | kicker: Common difficulties
**The register gap opens.** News, notices and essays use the written **-다 / -ㄴ다** style (*비가 온다*), not the 요 form. You need to read it now, even if you don't speak it.

**Comprehension outruns speech.** You'll understand far more endings than you can produce. Pick two new endings a week and force them into conversation.

:::mistake
- 피곤해서 때문에 못 갔어요. => 피곤하기 때문에 못 갔어요. (or 피곤해서 못 갔어요.)
Use one reason ending, not two.
:::
