TOPIK level 1 is Korean for daily survival: introducing yourself, buying something, ordering food. You understand and make simple sentences about yourself and your surroundings, slowly, with a patient listener. Everything below serves that.

## What you'll be able to do | short: I can… | kicker: Your goal
Treat this as the real test of the level: grammar you can't use in these situations isn't learned yet.

- [ ] Read and write Hangeul without looking it up
- [ ] Introduce yourself: your name, country and what you do
- [ ] Talk about your day with polite 요 endings
- [ ] Order in a café or restaurant and ask the price
- [ ] Count things and tell the time with both number systems
- [ ] Ask where something is and understand the answer
- [ ] Understand slow, clear speech on these topics

## Hangeul | short: Hangeul | kicker: Start here
Hangeul was designed to be learned in days, not months. Letters stack into syllable blocks: ㅎ + ㅏ + ㄴ = 한 and ㄱ + ㅜ + ㄱ = 국, so 한국 is "Korea".

| Letter | How it sounds | Example |
|---|---|---|
| ㅏ | "a" as in father | 나라 // country |
| ㅓ | an open "uh", as in up | 어머니 // mother |
| ㅗ | a rounded "o" | 오늘 // today |
| ㅜ | "oo" as in moon | 우유 // milk |
| ㅡ | "eu", lips flat | 음악 // music |
| ㅣ | "ee" as in see | 이름 // name |
| ㄱ ㄴ ㄷ ㄹ ㅁ | g/k, n, d/t, r/l, m | 가 나 다 라 마 // ga na da ra ma |
| ㅂ ㅅ ㅇ ㅈ ㅎ | b/p, s, silent or "ng", j, h | 바 사 아 자 하 // ba sa a ja ha |

:::tip
ㅇ is silent at the start of a block (아 is just "a") and sounds like "ng" at the bottom (강, river, is "gang").
:::

:::mistake
- 어 read as "o" => 어 is an open "uh"; 오 is "o"
That is why 서울 is romanised "Seoul": 서 is "seo", not "so".
:::

## Polite endings | short: 요 endings | kicker: Grammar · 1 of 4
Almost every sentence you say at this level ends in 요, the polite form that is safe with anyone you meet.

To say "I am a…", add **이에요** after a consonant and **예요** after a vowel. For verbs, take the dictionary form, drop 다, and add 아요 or 어요:

| Dictionary form | Polite form | Meaning |
|---|---|---|
| 가다 | 가요 | go |
| 먹다 | 먹어요 | eat |
| 마시다 | 마셔요 | drink |
| 하다 | 해요 | do |
| 공부하다 | 공부해요 | study |
| 좋아하다 | 좋아해요 | like |

:::examples
- 저는 학생**이에요**. // I'm a student.
- 저는 의사**예요**. // I'm a doctor.
- 매일 커피를 **마셔요**. // I drink coffee every day.
- 한국어를 **공부해요**. // I study Korean.
:::

:::tip
Stems with ㅏ or ㅗ take 아요, everything else takes 어요, and every 하다 verb becomes 해요. Say it with a rising tone and it's a question: 가요? means "Are you going?"
:::

:::mistake
- 저는 학생예요. => 저는 학생이에요.
학생 ends in a consonant (ㅇ), so it takes 이에요.
:::

:::practice
1. 저는 학생___. = 이에요
2. 저는 가수___. (singer) = 예요
3. 먹다 → ___ = 먹어요
4. 공부하다 → ___ = 공부해요
:::

## Particles | short: Particles | kicker: Grammar · 2 of 4
Korean marks each word's role with a small ending called a particle. The first form goes after a consonant, the second after a vowel.

| Particle | Its job | Example |
|---|---|---|
| 은 / 는 | the topic: "as for…" | 저는 마리아예요. // I'm Maria. |
| 이 / 가 | the subject, often new information | 고양이가 있어요. // There's a cat. |
| 을 / 를 | the object | 커피를 마셔요. // I drink coffee. |
| 에 | where you go, or when | 학교에 가요. // I go to school. |
| 에서 | where something happens | 카페에서 공부해요. // I study at a café. |

:::tip
The verb always comes last. Because the particles say who does what, the other words can move around more freely than in English.
:::

:::mistake
- 학교에서 가요. => 학교에 가요.
Going to a place takes 에; 에서 is for what you do once you're there.
:::

:::practice
1. 저___ 학생이에요. = 는
2. 커피___ 마셔요. = 를
3. 도서관___ 공부해요. = 에서
4. 집___ 가요. = 에
:::

## Two number systems | short: Numbers | kicker: Grammar · 3 of 4
Korean has two sets of numbers, and each job uses one of them.

| | Native Korean | Sino-Korean |
|---|---|---|
| 1 | 하나 (한) | 일 |
| 2 | 둘 (두) | 이 |
| 3 | 셋 (세) | 삼 |
| 4 | 넷 (네) | 사 |
| 5 | 다섯 | 오 |
| 10 | 열 | 십 |
| Used for | counting things, hours, age | minutes, money, dates, phone numbers |

The forms in brackets are used right before a counting word: 한 개 (one thing), 두 시 (two o'clock).

:::examples
- 세 시 삼십 분이에요. // It's 3:30.
- 커피 두 잔 주세요. // Two coffees, please.
- 만 원이에요. // It's 10,000 won.
- 스무 살이에요. // I'm twenty.
:::

:::mistake
- 삼 시 => 세 시
Hours use native Korean numbers, minutes use Sino-Korean: 세 시 삼십 분.
:::

:::practice
1. 커피 ___ 잔 주세요. (two) = 두
2. 지금 ___ 시예요. (one o'clock) = 한
3. 오천 ___이에요. (5,000 won) = 원
:::

## Questions and "not" | short: Questions | kicker: Grammar · 4 of 4
Question words sit where the answer would go, and the sentence still ends in 요.

| Word | Meaning | Example |
|---|---|---|
| 뭐 | what | 이게 뭐예요? // What is this? |
| 어디 | where | 화장실이 어디예요? // Where's the bathroom? |
| 언제 | when | 수업이 언제예요? // When is the class? |
| 누구 | who | 저 사람은 누구예요? // Who is that person? |
| 얼마 | how much | 이거 얼마예요? // How much is this? |
| 왜 | why | 왜 한국어를 공부해요? // Why do you study Korean? |

To say "not", put **안** right before the verb. For 하다 verbs, it goes right before 하다.

:::examples
- 오늘 학교에 **안** 가요. // I'm not going to school today.
- 고기를 **안** 먹어요. // I don't eat meat.
- 오늘은 공부 **안** 해요. // I'm not studying today.
:::

:::mistake
- 안 공부해요. => 공부 안 해요.
:::

:::practice
1. 이거 ___예요? (how much) = 얼마
2. 화장실이 ___예요? (where) = 어디
3. 저는 커피를 ___ 마셔요. (not) = 안
:::

## Words to know | short: Words | kicker: Vocabulary
These phrases get you through your first day. Learn them as whole phrases.

| Korean | English |
|---|---|
| 안녕하세요 | hello |
| 감사합니다 | thank you |
| 죄송합니다 | I'm sorry |
| 네 / 아니요 | yes / no |
| …주세요 | …, please (give me) |
| 괜찮아요 | it's okay, I'm fine |
| 몰라요 | I don't know |
| 다시 한 번 말해 주세요 | please say that again |
| 오른쪽 / 왼쪽 | right / left |
| 화장실 | bathroom |

Then build out from these topics: personal details, family, jobs, the home, food and drink, numbers and money, time and dates, the city and transport, your daily routine, and things you like.

## Your first conversation | short: Conversation | kicker: Put it together
Ordering in a café, using almost everything above.

:::dialogue
- 직원: 어서 오세요! // Welcome!
- 민지: 아이스 아메리카노 한 잔 주세요. // One iced americano, please.
- 직원: 여기서 드세요? // For here?
- 민지: 네, 여기서 마셔요. // Yes, for here.
- 직원: 사천오백 원이에요. // That's 4,500 won.
- 민지: 카드 돼요? // Can I pay by card?
- 직원: 네, 돼요. // Yes, you can.
- 민지: 감사합니다! // Thank you!
:::

## Watch out for | short: Watch out | kicker: Common difficulties
**The verb arrives last.** You can't tell whether a sentence is positive, negative or a question until it ends. Train yourself to hold the sentence and wait rather than translating as it goes.

**은/는 or 이/가?** This stays uncomfortable for a long time. Start with this rule of thumb: 은/는 introduces or contrasts a topic, 이/가 points out a subject. Exposure does the rest.

**Subjects disappear.** Korean drops anything the context already makes clear. A sentence with no subject is normal, not incomplete.

:::mistake
- 너 뭐 해? (to someone you just met) => 뭐 해요?
Casual speech with a stranger sounds rude. Use the 요 form until the other person suggests otherwise: being a little too polite is never noticed.
:::

## Ready for TOPIK 2? | short: Next | kicker: Next step
You're ready when Hangeul is automatic, the 요 form comes out without assembling it, and you can hold a slow conversation about yourself without rehearsing it first.

TOPIK 1 often takes around 100 to 150 hours of guided study for a European-language speaker, more than Spanish A1, mostly because of the writing system and the word order. Treat it as a rough scale, not a target. Next up is the Korean TOPIK 2 guide, which adds the connectors that turn short sentences into real conversation.
