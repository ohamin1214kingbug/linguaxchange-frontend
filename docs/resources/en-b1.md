En el B1 el inglés se convierte en una herramienta para conversaciones reales. Puedes dar tu opinión, imaginar qué harías, explicar cómo se hace algo y hablar de tu experiencia hasta hoy.

- [ ] Dar y justificar tu opinión sobre temas conocidos
- [ ] Hablar de situaciones posibles e imaginarias con if
- [ ] Contar desde cuándo haces algo
- [ ] Explicar cómo se hace o se fabrica algo

## Los condicionales | short: If | kicker: Gramática · 1 de 5
| Tipo | Estructura | Ejemplo |
|---|---|---|
| real (first) | if + presente, will + verbo | If it rains, I'll stay home. // Si llueve, me quedo en casa. |
| imaginario (second) | if + pasado, would + verbo | If I had money, I would travel. // Si tuviera dinero, viajaría. |

:::examples
- If you **study**, you'**ll pass**. // Si estudias, aprobarás.
- If I **were** you, I'**d call** her. // Yo que tú, la llamaría.
- What **would** you **do** if you **won** the lottery? // ¿Qué harías si te tocara la lotería?
:::

:::tip
*If I were you* es la forma correcta para dar consejos, incluso con I: **were**, no *was*.
:::

:::mistake
- If I would have money, I would travel. => If I had money, I would travel.
Nunca va would detrás de if.
:::

:::practice
1. If it ___ sunny tomorrow, we'll go to the beach. = is
2. If I ___ more time, I'd learn German. (have) = had
3. If I were you, I ___ apologise. = would
:::

## El present perfect con for y since | short: For / since | kicker: Gramática · 2 de 5
Para algo que empezó en el pasado y **sigue hasta ahora**, el inglés usa el present perfect, no el presente como el español.

:::examples
- I've **lived** here **for** five years. // Vivo aquí desde hace cinco años.
- She's **worked** there **since** 2020. // Trabaja ahí desde 2020.
- How long **have** you **known** him? // ¿Desde cuándo lo conoces?
:::

:::tip
**for** + duración (*for two years, for a week*); **since** + punto de inicio (*since Monday, since 2019*).
:::

:::mistake
- I live here since 2020. => I've lived here since 2020.
:::

:::practice
1. I've had this car ___ three years. = for
2. We've been friends ___ school. = since
3. How long ___ you studied English? = have
:::

## La voz pasiva | short: Pasiva | kicker: Gramática · 3 de 5
**be + participio** pone el foco en lo que se hace, no en quién lo hace. Es muy común en noticias, instrucciones y procesos.

:::examples
- English **is spoken** all over the world. // El inglés se habla en todo el mundo.
- The bridge **was built** in 1890. // El puente se construyó en 1890.
- The results **will be published** tomorrow. // Los resultados se publicarán mañana.
:::

:::tip
Muchas frases con "se" en español (*se habla*, *se construyó*) se traducen con la pasiva en inglés.
:::

:::practice
1. This cake ___ made with apples. (is / was) = is
2. The film was ___ in 2010. (make) = made
:::

## Oraciones de relativo | short: Relativos | kicker: Gramática · 4 de 5
| Pronombre | Para | Ejemplo |
|---|---|---|
| who | personas | The woman who lives next door is a doctor. // La mujer que vive al lado es médica. |
| which | cosas | The book which I bought is great. // El libro que compré es genial. |
| that | personas o cosas (informal) | The film that we saw was long. // La película que vimos era larga. |
| where | lugares | The town where I grew up is small. // El pueblo donde crecí es pequeño. |

:::tip
Cuando el pronombre es el objeto, en inglés se suele omitir: *The book **I** bought* = el libro que compré.
:::

:::practice
1. That's the man ___ helped me. = who
2. This is the café ___ we met. = where
:::

## Gerundio o infinitivo | short: -ing o to | kicker: Gramática · 5 de 5
Algunos verbos van seguidos de **-ing** y otros de **to + verbo**. Hay que aprenderlos con su forma.

| + -ing | + to |
|---|---|
| enjoy, finish, mind, avoid, suggest | want, decide, hope, plan, need |
| I enjoy reading. // Me gusta leer. | I want to travel. // Quiero viajar. |

:::mistake
- I enjoy to read. => I enjoy reading.
- I want going. => I want to go.
:::

:::practice
1. I've finished ___ my homework. (do) = doing
2. We decided ___ a car. (buy) = to buy
:::

## Pedir consejo | short: Conversación | kicker: Ponlo en práctica
:::dialogue
- Sara: I'm fed up with my job. I don't know what to do. // Estoy harta de mi trabajo. No sé qué hacer.
- Ben: If I were you, I'd look for something else. // Yo que tú, buscaría otra cosa.
- Sara: Maybe, but I've worked there for six years. // Puede, pero llevo seis años trabajando ahí.
- Ben: My sister works for a company that's hiring. Do you want her number? // Mi hermana trabaja en una empresa que está contratando. ¿Quieres su número?
- Sara: Yes, please! If she has time, I'll call her this week. // ¡Sí, por favor! Si tiene tiempo, la llamo esta semana.
- Ben: I'll send it now so you don't forget. // Te lo mando ahora para que no se te olvide.
:::

## Cuidado con | short: Cuidado | kicker: Dificultades frecuentes
**Los phrasal verbs.** Son la base del inglés hablado. Apréndelos en frases (*I gave up smoking*), no como listas sueltas.

**El inglés hablado real.** Los nativos contraen y enlazan (*gonna, wanna, I'd've*). Entiéndelo, pero escribe las formas completas.

:::mistake
- I'm agree with you. => I agree with you.
Agree es un verbo: no lleva am.
:::
